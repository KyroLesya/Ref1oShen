## Тема
Методы интеллектуального анализа данных на примере стран мира.

## Описание проекта
В этом репозитории представлен код для анализа данных о странах мира. Работа направлена на проверку двух гипотез:

1. Чем больше площадь страны, тем больше её население.  
2. Валюту "Евро" используют только европейские страны.

## Содержание кода
- **Загрузка и очистка данных**: скрипт загружает CSV с данными о странах, оставляет нужные столбцы (`name`, `area`, `population`, `continent`, `currency_name`) и удаляет пропущенные значения.  
- **Анализ зависимости площади и населения**: строится scatter plot на логарифмических осях и вычисляется коэффициент корреляции Пирсона.  
- **Анализ использования евро**: строится график количества стран с валютой "Евро" по континентам и проверяется, используются ли евро только в европейских странах.

## Файлы
- `countries.csv` – исходный датасет.  
- `countries_clean.csv` – подготовленный и очищенный датасет.  
- `analysis.ipynb` – Jupyter Notebook с кодом анализа и визуализациями.  

## Использование
1. Клонируйте репозиторий.  
2. Убедитесь, что установлены библиотеки `pandas`, `matplotlib`, `numpy`.  
3. Запустите `analysis.ipynb` в Jupyter Notebook.  

## Результаты
- Графики зависимости населения от площади.  
- Проверка гипотезы о плотности населения и использовании евро.
